## 🚀 Overview
This repository contains the complete source code for my personal portfolio and blog website. Designed and developed as a first-semester BCA student at **Silver Oak University, Ahmedabad**, this project showcases my background, technical skill matrix, emerging interests, and direct contact channels.

### ✨ Key Features
- **Semantic HTML5 Outline**: Clean, accessible document structure utilizing `<header>`, `<section>`, `<ul>`, and `<footer>`.
- **Single-Page Anchor Navigation**: Quick navigation strip allowing instant smooth jumps between sections without page reload.
- **Neon-Cyan Hover Illumination**: Custom interactive micro-interactions (`section:hover`) with background inversion (`#111111`) and glowing box-shadow (`10px 10px 10px #00b7ff`).
- **Responsive Layout**: Fluid centered card architecture (`width: 70%; margin: 25px auto`) adapting across desktop, tablet, and mobile screens.
- **Zero Dependencies**: Pure vanilla code with zero frameworks (no Bootstrap, no Tailwind, no JavaScript), delivering 100/100 performance scores.
- **Global Edge Deployment**: Published to Surge CDN with auto-renewing SSL certificate and global CDN caching.

## 💻 Local Development
To run this project locally on your machine:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Rudraksh-Rajpurohit/Personal-Blog.git
   cd Personal-Blog
   ```
2. Open `index.html` in your web browser:
   - Double click `index.html`, or
   - Use VS Code Live Server extension.
